# 🕵️ CODENAMES : SPYMASTER AI (코드네임 팀장 모드 웹앱)

> **보드게임 '코드네임(Codenames)' 혼자 연습용 웹앱**  
> 앱(AI)이 직접 **팀장(스파이마스터)** 이 되어 암호 힌트를 주면, 현장 요원이 되어 정답 카드를 맞추는 실전 훈련 웹앱입니다.  
> **음성(STT/TTS)** 및 **텍스트 입력**, **마우스 클릭**을 모두 완벽하게 지원합니다.

---

## ✨ 핵심 기능

1. **지능형 AI 팀장 (스파이마스터)**
   - 비밀 키카드를 분석하여 아군 카드들을 묶는 최적의 힌트(단어 1개 + 숫자)를 실시간 연산하여 제공합니다.
   - **암살자(Assassin) 회피 알고리즘**: 암살자 카드와 조금이라도 연관된 힌트는 사전에 엄격히 배제합니다.
   - **실제 정식 룰 준수**: 현재 테이블에 놓인 단어 자체는 힌트로 사용하지 않습니다.

2. **다양한 입력 방식 (음성 & 텍스트)**
   - 🎙️ **말로 지목하기 (음성인식 STT)**: 마이크 버튼을 켜고 "사과", "피아노" 등 단어를 말하면 자동으로 해당 카드가 선택됩니다.
   - ⌨️ **텍스트 타이핑**: 하단 입력창에 단어를 직접 입력하고 엔터를 눌러 지목할 수 있습니다.
   - 🖱️ **직접 클릭**: 화면의 카드를 마우스/터치로 직접 클릭할 수 있습니다.
   - 📢 **팀장 음성 낭독 (TTS)**: 팀장이 "레드 팀장 힌트입니다: 우주, 2장"을 음성으로 브리핑해 줍니다.

3. **3단계 난이도 및 팀 선택**
   - **초급 (Agent)**: 2장 단위의 매우 직관적이고 안전한 힌트 제공, 여유로운 상대팀 템포.
   - **중급 (Special Agent)**: 표준 정식 코드네임 규칙, 균형 잡힌 AI 팀장.
   - **고급 (Master Spy)**: 3~4장 다중 연결 힌트 적극 탐색, 상대팀 AI의 빠른 카드 확보로 고난도 스피드런.
   - **레드(RED) / 블루(BLUE)** 팀 색상 자유 선택.

4. **실제 코드네임 카드 단어 풀 & 중복 방지 시스템**
   - 실제 보드게임 공식 한국어판 기준 대표 단어 200개 이상의 방대한 풀 탑재.
   - 이전 게임에서 등장했던 단어를 기억하여, 다음 게임에서 동일한 카드가 연속으로 출현하지 않도록 방지합니다.

5. **최상급 비주얼 & 사운드 디자인**
   - 007 / MI6 기밀 작전실 테마의 네온 다크 HUD.
   - 실제 린넨 카드 질감과 실감 나는 3D 플립(카드 뒤집기) 애니메이션.
   - Web Audio API 기반 오리지널 전술 사운드 (외부 다운로드 딜레이 0, 비용 0원).
   - 게임 종료 후 **비밀 키카드(Secret Keycard) 25장 전체 원본 복기 뷰** 제공.

> [!IMPORTANT]
> **PWA 필수 가이드라인**: 캐시가 꼬일 수 있으니 꼭 기존 앱을 완전히 삭제하고 설치하셔야 합니다. (또는 브라우저 강력 새로고침 `Ctrl + F5`)

## 🚀 바로 실행하기

### 방법 1. 윈도우 원클릭 실행 (가장 추천)
프로젝트 폴더 내의 **`start.bat`** 파일을 더블 클릭하면 브라우저가 열리며 즉시 실행됩니다.

### 방법 2. 터미널 명령어로 실행
```bash
# 1. 패키지 설치 (최초 1회)
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하시면 됩니다.

### 방법 3. 프로덕션 빌드 및 실행
```bash
npm run build
npm run preview
```

## 🛠️ 기술 스택 및 비용 정보
- **프론트엔드**: React 18, TypeScript, Tailwind CSS, Lucide React, Canvas-Confetti
- **빌드 도구**: Vite 5
- **음성 엔진**: Web Speech API (`SpeechRecognition`, `SpeechSynthesis`) - **100% 무료 / 로컬 브라우저 구동**
- **사운드 엔진**: Web Audio API (합성 오실레이터) - **100% 무료**
- **비용**: 외부 유료 API를 전혀 사용하지 않아 **운영 비용 0원**입니다.
